# setwemu-backend
This backend is built using Node.js and Express, connecting to Firebase

How to run locally:
1. Clone the repo.
2. Navigate to `setwemu-backend`.
3. Run `npm install` to get dependencies.
4. Create a `.env` file and type `PORT=5000`.
5. Add the `serviceAccountKey.json` to the root folder.
6. Run `node index.js`.
